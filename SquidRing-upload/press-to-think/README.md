# Press to Think — V2

V2 定位：在 V1 的按键提问与对话闭环上，加入语音控制的轻量 Agent 能力；提升输入识别、播放摘要与音效反馈。软件版本固定为 2.0.0，硬件仍为独立验证中的原型。

## V2 改动

- 语音复合指令：同一句中可新建话题、切换快速/深度模式并提出问题；可按语义找回旧会话。
- 腾讯云 ASR 与 DeepSeek 语义纠错；保留原始转写以便核对。浏览器输入失败时可回退。
- 完整回答与口语摘要分离；双击才播放，长按可中断生成或播报。播放和收音互斥。
- 腾讯精品 TTS 可选，失败时回退系统声音；完成提示使用短音效与手机振动。
- 会话本地保存；新话题只有出现第一条有效消息才创建。

安卓版伴侣工程位于 [`../android/PressToThinkV2`](../android/PressToThinkV2/README.md)。当前安卓版通过 USB 连接 Mac 上的 V2 本地服务，不是脱离电脑运行的正式版。

这是一个不依赖前端框架的本地软件原型，用屏幕按钮或空格键模拟戒指，验证完整产品交互：

- 长按立即开始语音识别，松开后发送
- DeepSeek V4 Pro 单一模型，快速/深度模式切换思考强度
- 同一 Thought Thread 连续对话，历史会话保存在浏览器本地
- 完整回答先显示在 App，再由独立的第二次模型调用真正压缩成口语总结，等待用户双击播放
- 播放时长按立即停止并重新听用户说话
- 语音指令“新话题”“切换到深度模式”“继续之前……的对话”
- 设置面板可滚动，保存按钮始终可见

## 启动

macOS 最简单的启动方式：双击项目里的 `启动 Press to Think.command`，并在使用期间保持弹出的终端窗口开启。它会自动打开正确页面：

```text
http://localhost:3210
```

也可以在本目录手动运行：

```bash
npm start
```

然后打开：

```text
http://localhost:3210
```

首次使用：

1. 点击右上角齿轮。
2. 填入一枚新的 DeepSeek API Key。Key会保存在本机后端，Chrome和其他浏览器共用；不要继续使用已经公开过的 Key。
3. 保存设置。
4. 允许浏览器使用麦克风。
5. 按住红色按钮说话，松开提交；快速轻点两次播放最近回答。

请使用 Chrome/Chromium 测试语音。ChatGPT 内置页面和 Safari 不作为当前语音Demo的支持环境；若语音能力不可用，可使用右侧文字输入完成其余流程测试。

## 当前边界

- 网页版语音识别可使用浏览器或腾讯云 ASR；安卓版使用原生手机麦克风和腾讯云 ASR。
- TTS 可使用腾讯精品音色；无法调用时回退系统声音。
- API Key 仅适合本机 Demo：Key保存在被 Git 忽略的 `data/settings.json` 中，并由本地服务请求 DeepSeek。正式产品必须改为账户后端。
- 真实戒指接入时，用 BLE 事件替换 `pointerdown / pointerup`，并增加戒指音频流接收；界面、会话和模型逻辑无需重写。
