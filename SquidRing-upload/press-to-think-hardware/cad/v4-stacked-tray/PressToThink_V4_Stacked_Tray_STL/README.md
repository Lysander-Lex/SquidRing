# Press to Think V4：三件堆叠低占地结构

## 分层

```text
1.2 mm薄上盖（按钮头穿出）
──────────────────────
电池 16×12×3.5 │ 按钮 6×6×5
        独立上层托盘
──────────────────────
XIAO 22.5×18×5.5
──────────────────────
壳体底板＋18 mm圆形戒圈
```

## 尺寸

- 顶面：27.5 × 27.5 mm
- 戒圈内径：18 mm
- 戒圈顶部以上总厚度（含上盖）：约14.6 mm
- 比V3顶面按钮厚盖方案降低约4 mm

## 为什么不会压坏或晃动

- XIAO位于底层，由四周低限位筋阻止平移。
- 上层托盘由壳体四角支柱承重，不把电池和按钮重量传到XIAO元件上。
- 电池与按钮并排位于托盘上，分别有低限位筋。
- 电池顶部与薄上盖之间使用约1–1.5 mm软EVA泡棉补偿高度差；不能硬压。
- 按钮本体5 mm高，接近上层空间高度，按钮头直接穿过上盖3.4 mm孔。

## 走线

- XIAO左右各约3.35 mm竖向走线区。
- 上层托盘比仓体窄，两侧各约5.25 mm开放空间，可把按钮线和电池线引到底层。
- 按钮引脚掰平后朝托盘前后方向布置，分别绝缘。
- 导线用Kapton胶带固定在侧壁，不能进入上盖接缝。
- 上层托盘可以取出，方便检修焊点和更换电池。

## 装配顺序

1. XIAO装入底层，USB-C对准开口。
2. 将按钮引脚掰平、绝缘并接线。
3. 电池与按钮放入独立托盘，导线从托盘侧边落到底层。
4. 托盘放在四角承重支柱上。
5. 电池上方贴软泡棉，确认没有鼓包或硬压。
6. 合上薄顶盖，确认所有导线低于接缝。
