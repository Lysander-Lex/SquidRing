# Press to Think V3：直接圆形戒圈＋防夹线仓位

## 外形

- 18 mm内径圆形戒圈直接连接方形印章平台。
- 无肩部曲面、无阶梯过渡。
- 方形顶面28 × 28 mm。
- 3 mm圆形按钮位于顶面中央。

## 线材余量

- XIAO宽18 mm，电子仓内部宽25.2 mm。
- 主板两侧各留约3.6 mm走线区，容纳0.7 mm导线及弯曲余量。
- 主板前后各留约1.35 mm；USB-C一端另有开放接口。
- 电池限位筋在四边中央都有4 mm缺口，电池线可以从任一方向引出。
- 上盖只使用八个短定位片，不使用连续定位边；两侧长缺口作为过线通道。
- 四个低矮线扣用于把导线保持在接缝以下，线仍需用Kapton胶带固定。

这不是“正好卡死”的尺寸。主板由两条边缘托台承重，电池由断开的限位筋限制水平移动，导线拥有独立通道。

## 安装

1. 电池放入底部限位筋内，线从就近的4 mm缺口引出。
2. 在电池上覆盖0.5–0.7 mm绝缘片。
3. XIAO长边放在两条托台上。
4. 导线沿主板两侧3.6 mm走线区布置，穿过线扣下方或贴在线扣内侧。
5. 导线用Kapton胶带固定，焊点附近保留3–5 mm松弛弯。
6. 顶面按钮装入上盖中央，按钮腿剪短或向两侧弯折并绝缘。
7. 合盖前检查所有线均低于壳体边缘，没有进入定位片接触区域。

软包电池不能过盈安装、不能被硬质上盖直接压住，也不能用瞬干胶永久粘死。
