# Press to Think V1.0：戒指按钮样机组装指南

本阶段的目标是把 XIAO nRF52840 Sense 做成蓝牙键盘：按钮按下等于空格键按下，按钮松开等于空格键松开。Press to Think V1.0 网页使用电脑或手机自身的麦克风录音。

## 1. 准备工具

- Seeed XIAO nRF52840 Sense
- 6×6×5 mm 四脚轻触按钮
- 401215、3.7 V、60 mAh、带保护板锂电池
- 30 AWG 线：黄色作为按钮信号，黑色作为地线
- 能传输数据的 USB-C 线
- 细头恒温烙铁、焊锡、助焊剂
- 万用表（至少需要蜂鸣/通断档）
- 镊子、剪线钳、剥线钳
- 耐高温胶带、热缩管或液体绝缘胶

## 2. 先不要接电池

整个首次烧录和按钮测试阶段只使用 USB-C 供电。电池最后再焊，防止焊接时短路或反接。

## 3. 找出按钮的正确两只脚

四脚按钮内部是“两组常通脚”。同一组的两脚在未按下时已经连通，不能把它们分别接到 D1 和 GND。

1. 万用表切换到蜂鸣/通断档。
2. 任取两脚测量。
3. 未按按钮就响：这两脚属于同一组，不使用这对。
4. 未按不响、按下才响：这两脚可以分别连接 D1 和 GND。
5. 用记号笔标记选中的两脚。

## 4. 焊接按钮

1. 剪一根约 5–8 cm 黄色线和一根约 5–8 cm 黑色线。
2. 两端各剥去约 2 mm 外皮。
3. 给线头、按钮脚、XIAO 的 D1 和 GND 焊盘分别少量上锡。
4. 黄色线一端焊到 D1，另一端焊到按钮选中的一只脚。
5. 黑色线一端焊到 GND，另一端焊到按钮另一组的一只脚。
6. 万用表复查：松开按钮时 D1 与 GND 不通；按下时导通。
7. 检查 D1、旁边焊盘之间没有锡桥。

接线只有这一条：`D1 → 按钮 → GND`。不需要给按钮接 3.3 V。

## 5. 安装 Arduino IDE 和开发板支持

1. 安装并打开 Arduino IDE 2.x。
2. 进入 `Arduino IDE → Settings/Preferences`。
3. 在 `Additional Boards Manager URLs` 中加入：
   `https://files.seeedstudio.com/arduino/package_seeeduino_boards_index.json`
4. 打开 `Tools → Board → Boards Manager`。
5. 搜索 `Seeed nRF52 Boards` 并安装。蓝牙按钮阶段不要选择 mbed-enabled 版本。
6. 打开 `Library Manager`，搜索并安装 `Adafruit TinyUSB Library`。
7. 进入 `Tools → Board`，选择 `Seeed XIAO nRF52840 Sense`。

## 6. 烧录按钮固件

1. 用数据 USB-C 线连接 XIAO 和电脑。
2. 在 Arduino IDE 打开 `firmware/PressToThinkButtonV1/PressToThinkButtonV1.ino`。
3. 进入 `Tools → Port`，选择新出现的 XIAO 端口。
4. 点击左上角 Verify，等待编译完成。
5. 点击 Upload，等待出现上传成功。
6. 上传失败或找不到端口时，快速双击 XIAO 上很小的 Reset 键，让板子进入 Bootloader，再重新选择端口上传。
7. 若仍报 DFU/串口错误，在 `Tools → Programmer` 选择 `Bootloader DFU for Bluefruit nRF52` 后重试。

## 7. 蓝牙配对

1. 上传成功后拔掉再插上 USB-C，让开发板重新启动。
2. 打开 macOS `系统设置 → 蓝牙`。
3. 等待出现 `PressToThink Ring V1.0`。
4. 点击连接。系统会把它识别为蓝牙键盘。
5. 如果系统弹出“识别键盘”向导，可以关闭或跳过，不需要判断键盘布局。

## 8. 测试网页控制

1. 使用 Chrome 打开 Press to Think V1.0。
2. 点击一下网页，让网页获得键盘焦点。
3. 在地址栏左侧的网站权限中允许麦克风。
4. 按住实体按钮至少 1 秒。
5. 网页进入 LISTENING，听到提示音后开始讲话。
6. 松开实体按钮，网页停止录音、纠错并提交。
7. 快速短按两次按钮，网页播放最近一次口语总结。

如果按按钮导致页面滚动，说明网页没有获得焦点：先用鼠标点击红色按钮附近，再测试。

## 9. 最后接电池

1. 确认 USB 供电下按钮和蓝牙已经完全正常。
2. 拔掉 USB-C。
3. 确认电池是 3.7 V、带保护板，红线为正极、黑线为负极。
4. 在 XIAO 背面的电池焊盘确认 `+` 和 `-` 标记。
5. 红线焊到电池正极 `+ / BAT+`，黑线焊到负极 `- / BAT-`。不要接到 5V 或 3V3。
6. 红黑线分开处理；禁止同时剪断两根电池线，避免剪钳造成短路。
7. 单次接触电池线焊点尽量控制在 2–3 秒内，不要直接加热或刺穿电芯。
8. 每个裸露焊点单独绝缘，再整体固定电池。电池不能被按钮或外壳硬边挤压。
9. 开机确认蓝牙设备重新出现。
10. 通过 XIAO 的 USB-C 给电池充电。60 mAh 电池保持默认约 50 mA 充电档，不要改成 100 mA。

## 10. 做成戒指形态时的摆放

- XIAO 的板载麦克风孔朝外，不能被胶封死。
- 天线一端远离电池、金属戒圈和大块铜箔，至少留出几毫米净空。
- 电池与电路板之间垫绝缘片。
- 按钮帽略高于外壳，周围留活动间隙。
- 第一版用塑料/树脂外壳，不要直接用全金属壳包住天线。
- 在完全验证之前不要用胶永久灌封，先用胶带或可拆螺丝固定。

## 11. 验收顺序

必须逐项通过，不要一次把所有零件塞进外壳：

1. USB 能识别 XIAO。
2. Blink 示例可以上传。
3. 按钮通断正确。
4. 按钮固件上传成功。
5. 电脑能发现并连接蓝牙键盘。
6. 文本框中按住实体按钮能产生空格按下/松开效果。
7. Press to Think 网页能开始和停止录音。
8. 双击实体按钮能播放总结。
9. 拔掉 USB 后，电池供电仍能完成以上操作。
10. 最后才装入临时戒指外壳。

## 12. 戒指麦克风属于下一阶段

当前固件没有传输 XIAO 的板载麦克风音频。下一阶段需要：PDM 采集 16 kHz 单声道音频、压缩、通过自定义 BLE GATT 分片发送、网页/手机接收并送入专业中文 ASR。不要在按钮链路尚未通过时同时开发这一部分。
